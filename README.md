# 🛒 E-commerce Data Analytics Case Study

## 🚀 Live Demo
🔗 Streamlit App: https://ecommerce-sales-analytics-bu8ozfu6de5mi75nazhffu.streamlit.app/

## 🔍 Business Problem
E-commerce businesses collect large volumes of customer and transaction data, but often fail to leverage it effectively for decision-making.

## 🎯 Objective
To analyze customer and transaction data in order to improve:
- Conversion Rate  
- Customer Retention  
- Revenue Growth  

## 🛠 Tools & Technologies
- SQL (Data Extraction & Querying)
- Excel / Python (Data Analysis)
- Data Analytics Concepts (KPIs, Metrics)

## 📁 Dataset
Simulated dataset containing:
- Customer data  
- Order transactions  
- User activity  

## ⚙️ Approach
1. Identified key datasets required for analysis  
2. Defined business KPIs (Conversion, Retention, AOV, CLV)  
3. Wrote SQL queries to extract insights  
4. Analyzed trends and patterns  

## 📊 Key KPIs
- **Conversion Rate** → % of users who completed purchase  
- **Customer Retention Rate** → Repeat customers over time  
- **Average Order Value (AOV)** → Revenue per order  
- **Customer Lifetime Value (CLV)** → Long-term customer value  

## 💡 Key Insights
- Retention has a higher impact on long-term revenue than acquisition  
- Increasing AOV significantly improves profitability  
- Tracking user behavior is essential for marketing ROI  

## 📈 Business Impact
This analysis demonstrates how data-driven insights can:
- Improve customer retention strategies  
- Optimize pricing and bundling  
- Increase overall revenue
